# Отчет по лабораторной работе 1

## Что было сделано

В рамках первой лабораторной работы для проекта Wine Quality MLOps были подготовлены два независимых пайплайна:

- `Lab1 CI` для автоматической сборки Docker image и отправки его в Docker Hub.
- `Lab1 CD` для функционального тестирования сервиса модели по сценарию.

## Реализация

### GitHub Actions

- `Lab1 CI` реализован в `.github/workflows/ci.yml`.
- Триггеры: `pull_request` в ветку `main` и `workflow_dispatch`.
- Этапы: установка зависимостей, `dvc repro`, `pytest`, сборка Docker image, push image в Docker Hub, генерация `dev_sec_ops.yml`.

- `Lab1 CD` реализован в `.github/workflows/cd.yml`.
- Триггеры: `workflow_dispatch`, `schedule`, `workflow_run` после успешного `Lab1 CI`.
- Этапы: подготовка окружения, запуск `docker compose`, поднятие API и PostgreSQL, прогон функционального сценария, сохранение отчета о сценарии.

### Jenkins

Для локальной проверки были созданы отдельные Jenkins jobs:

- `WineQuality-Lab1-CI`
- `WineQuality-Lab1-CD`

Проверка в Jenkins на локальной машине выполнена успешно:

- `WineQuality-Lab1-CI #1` завершилась со статусом `SUCCESS`, собрала и отправила image `ntfs121/wine-quality-mlops` в Docker Hub.
- `WineQuality-Lab1-CD #5` завершилась со статусом `SUCCESS` и успешно выполнила функциональный сценарий через `docker-compose`.

## Итог

Требования первой лабораторной работы выполнены:

1. CI pipeline автоматически стартует по pull request в основную ветку репозитория и публикует Docker image в Docker Hub.
2. CD pipeline выполняет функциональное тестирование по сценарию и может запускаться вручную, по расписанию или после успешного CI.

## Основные артефакты

- GitHub Actions: `.github/workflows/ci.yml`, `.github/workflows/cd.yml`
- Jenkins pipelines: `jenkins/lab1-ci.Jenkinsfile`, `jenkins/lab1-cd.Jenkinsfile`
- Docker image: `ntfs121/wine-quality-mlops`
- Актуальный дистрибутив модели: `wine-quality-mlops-lab1-distribution.zip`
